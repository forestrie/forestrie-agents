# Generic harness

Any agent that reads markdown can use this repo directly.

1. Read [AGENTS.md](../AGENTS.md)
2. Load one [arc-context](../arc-context/) file if needed
3. Read the working repo's `forest/agents/AGENTS.md` or root `AGENTS.md`
4. Load only the workflow command or skill invoked by the user

No harness-specific format required. Prefer plain markdown with relative links.

Platform depth: [devdocs](https://github.com/forestrie/devdocs).
